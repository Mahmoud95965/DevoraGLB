# DevoraGLB - شركة تطوير مواقع إلكترونية مدعومة بالذكاء الاصطناعي

## 🌟 نظرة عامة

DevoraGLB هي شركة متخصصة في إنشاء وبيع المواقع الإلكترونية المزودة بالذكاء الاصطناعي. نحول أفكارك إلى مواقع احترافية مدعومة بأحدث تقنيات الذكاء الاصطناعي والتعلم الآلي.

## ✨ المميزات

- 🤖 **مواقع مدعومة بالذكاء الاصطناعي** - روبوتات محادثة ذكية، توصيات مخصصة، تحليل بيانات متقدم
- 💻 **تطوير مواقع مخصصة** - تصميم متجاوب، أداء عالي السرعة، تحسين محركات البحث
- 🎨 **تصميم UI/UX احترافي** - تصميم عصري وجذاب، تجربة مستخدم محسّنة، هوية بصرية متكاملة
- 🌙 **الوضع الليلي** - دعم كامل للوضع الليلي
- 📱 **تصميم متجاوب** - يعمل بشكل مثالي على جميع الأجهزة
- 🌐 **دعم اللغة العربية** - واجهة RTL كاملة

## 🛠️ التقنيات المستخدمة

- **Frontend**: React 18 + TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Backend**: Firebase (Authentication, Firestore, Storage)
- **Build Tool**: Vite
- **Routing**: React Router v6

## 📦 التثبيت

```bash
# استنساخ المشروع
git clone https://github.com/yourusername/devoraglb.git

# الانتقال إلى مجلد المشروع
cd devoraglb

# تثبيت الحزم
npm install

# تشغيل المشروع في وضع التطوير
npm run dev
```

## 🔧 الإعداد

1. أنشئ ملف `.env` في المجلد الرئيسي
2. أضف متغيرات Firebase الخاصة بك:

```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```

## 📄 الصفحات المتاحة

- **الصفحة الرئيسية** (`/`) - عرض الخدمات والمميزات
- **مشاريعنا** (`/portfolio`) - عرض المشاريع الجاهزة للبيع
- **تفاصيل المشروع** (`/portfolio/:id`) - تفاصيل المشروع مع رابط المعاينة
- **لوحة تحكم المشاريع** (`/admin/projects`) - إدارة المشاريع (للمسؤول فقط)
- **من نحن** (`/about`) - معلومات عن الشركة
- **تواصل معنا** (`/contact`) - نموذج التواصل
- **الشروط والأحكام** (`/terms`) - شروط الاستخدام
- **سياسة الخصوصية** (`/privacy`) - سياسة الخصوصية

## 🔐 لوحة تحكم المسؤول

للوصول إلى لوحة تحكم المشاريع:
1. الانتقال إلى `/admin/projects`
2. إدخال كلمة المرور: `Mahmoud159208@#$`
3. بعد المصادقة، يمكنك:
   - إضافة مشاريع جديدة
   - تعديل المشاريع الموجودة
   - حذف المشاريع
   - رفع صور المشاريع إلى Firebase Storage
   - إدارة تفاصيل المشروع (العنوان، الوصف، السعر، المميزات، التقنيات)

**ملاحظة**: كلمة المرور محفوظة في الجلسة (Session Storage) ولن تحتاج لإدخالها مرة أخرى حتى تغلق المتصفح.
